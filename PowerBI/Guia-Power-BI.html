Analizar la latencia en Power BI Desktop

Eureka_CloudSpeed · funciona con la versión gratuita de Power BI Desktop

Qué contiene esta carpeta

ArchivoPara qué sirve
Eureka_CloudSpeed_PowerBI.xlsxTodo el histórico de mediciones en tres tablas de Excel: Mediciones, Regiones (con latitud y longitud) y Sesiones. Se sobrescribe en la misma ruta cada vez que pulsas Power BI (histórico).
Abrir_en_Power_BI.pbidsDoble clic: abre Power BI Desktop conectado al libro anterior.
Medidas.daxMedidas listas para pegar (P50, P95, pérdida, mejor región, color por latencia…).
Consultas.pqAlternativa: consultas de Power Query que leen directamente los CSV de la carpeta Datos, sin volver a exportar.

1. Cargar los datos

  1. Instala Power BI Desktop (gratuito, desde Microsoft Store o la web de Microsoft).
  2. Haz doble clic en Abrir_en_Power_BI.pbids. Si no se abre, en Power BI Desktop usa Obtener datos > Libro de Excel y elige Eureka_CloudSpeed_PowerBI.xlsx.
  3. En el navegador marca las tablas Mediciones, Regiones y Sesiones (las del icono de tabla, no las hojas) y pulsa Cargar.
  4. En la vista de Modelo comprueba (o crea arrastrando) las relaciones:
    • Mediciones[Clave] → Regiones[Clave] (varios a uno)
    • Mediciones[SesionId] → Sesiones[SesionId] (varios a uno)

Para actualizar: mide de nuevo, pulsa Power BI (histórico) en Eureka_CloudSpeed y después Inicio > Actualizar en Power BI Desktop. Si usas Consultas.pq, basta con Actualizar.

2. Crear las medidas

Selecciona la tabla Mediciones > Inicio > Nueva medida y pega cada medida de Medidas.dax. Las principales:

Latencia P50 (ms) = CALCULATE ( PERCENTILE.INC ( Mediciones[TCP_ms], 0.5 ), Mediciones[Correcto] = TRUE () )
Latencia P95 (ms) = CALCULATE ( PERCENTILE.INC ( Mediciones[TCP_ms], 0.95 ), Mediciones[Correcto] = TRUE () )
Pérdida % = DIVIDE ( CALCULATE ( COUNTROWS ( Mediciones ), Mediciones[Correcto] = FALSE () ), COUNTROWS ( Mediciones ) )

Usa la mediana (P50) en lugar de la media: un pico puntual no la distorsiona. El P95 indica cómo de estable es la conexión.

3. Visuales recomendados

VisualCampos
Gráfico de barras agrupadas (ranking)Eje Y: Regiones[Región] · Eje X: Latencia P50 (ms) · Leyenda: Regiones[Nube]. Ordena de menor a mayor. Opcional: color con formato condicional usando Color latencia.
Gráfico de líneas (evolución)Eje X: Mediciones[FechaHora] · Eje Y: Latencia P50 (ms) · Leyenda: Regiones[Región]. Filtra las 5 primeras con N superior.
MapaLatitud: Regiones[Latitud] · Longitud: Regiones[Longitud] · Tamaño: Muestras · Información sobre herramientas: Latencia P50 (ms). Color: Color latencia.
Matriz (Azure frente a AWS)Filas: Regiones[Geografía] · Columnas: Regiones[Nube] · Valores: Mejor P50 (ms) y Mejor región.
TarjetasMejor región, Mejor P50 (ms), Pérdida %, Muestras.
SegmentacionesMediciones[Etiqueta] (oficina, casa, VPN…), Mediciones[Equipo], Mediciones[Fecha], Regiones[Nube], Regiones[Geografía].

El visual de Mapa puede venir desactivado: actívalo en Archivo > Opciones y configuración > Opciones > Seguridad > Usar los objetos visuales de mapa y mapa coroplético. Envía las coordenadas a Bing Maps para dibujar el mapa.

4. Acumular histórico automáticamente

Para comparar horas del día o días de la semana, programa mediciones con el Programador de tareas de Windows usando el modo sin interfaz. Cada ejecución añade sus resultados a la carpeta Datos:

Eureka_CloudSpeed.cmd -SinInterfaz -Etiqueta "Oficina" -Muestras 5
Eureka_CloudSpeed.cmd -SinInterfaz -Geografia Europa -Rondas 12 -Intervalo 300 -Exportar PowerBI

La etiqueta te permite comparar redes (fibra, 4G, VPN…) con la segmentación de Etiqueta.

Qué permite la versión gratuita

  • Sí: crear y usar el informe en Power BI Desktop, actualizar los datos y guardar el archivo .pbix para enviárselo a quien también tenga Power BI Desktop.
  • No: compartir el informe en el servicio de Power BI (powerbi.com) con otras personas ni programar actualizaciones en la nube; para eso hace falta una licencia Pro, Premium por usuario o capacidad Fabric.
  • Cuidado con Publicar en la web: hace el informe público en Internet para cualquiera que tenga el enlace.

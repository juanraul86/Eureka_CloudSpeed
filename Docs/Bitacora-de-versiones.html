Cómo se mantiene esta bitácora

  • Cada cambio se registra en la versión en curso. La versión está en Modules\Core.psm1 ($script:Version) y en Build\Launcher.cs.
  • Cada compilación genera Dist\MANIFIESTO-v<versión>.txt: fecha, si está firmado, huella SHA-256 de cada artefacto y la lista exacta de archivos publicados. Ese archivo es la prueba de qué se publica en cada versión.
  • Toda operación que crea o borra recursos en Azure o AWS se anota en el registro de operaciones en la nube. Norma: lo que se crea para una prueba se borra al terminarla.
  • Formato de versión: MAYOR.MENOR.PARCHE (menor = funciones nuevas; parche = correcciones).

1.3.0 · 19/11/2026 · Estado de servicios, pruebas sin costes residuales y privacidad

Nuevo

  • Sección Estado de servicios: estado oficial de Azure, Microsoft 365 (empresarial y consumo), Power Platform, Azure DevOps, AWS, Google Cloud, Google Workspace, GitHub y Cloudflare; comprobación propia desde la red (DNS, TCP y HTTPS de 20 servicios); diagnóstico combinado para caídas globales con la página de estado caída, caídas no publicadas, incidencias confirmadas y problemas de conexión; comprobación automática; histórico para evidencias de SLA.
  • Probar-Velocidad.ps1: crea, mide y borra siempre lo creado en Azure o AWS, y verifica que no queda nada que genere cargos.
  • Al terminar una prueba se elige mantener o cerrar la sesión de la CLI (-MantenerSesion / -CerrarSesion); -Tenant para cuentas de Azure en varios directorios.
  • -Eliminar -Confirmar en los scripts de Azure y AWS (borrado sin pregunta interactiva para pruebas automáticas).
  • Conservación del histórico (12 meses por defecto, configurable) y botón Borrar todo el histórico (RGPD, art. 5.1.e y 17).
  • Manifiesto de publicación por versión en Dist\.
  • Documentación: técnica, manual de uso, esta bitácora y revisión de seguridad v2.

Cambios

  • S3: una URL de subida por conexión (4); evita el error 503 Slow Down al escribir en la misma clave.
  • La sección Velocidad recarga sola los endpoints cuando un script cambia la configuración.
  • Guardado de Config\velocidad.json blindado: copia .bak con permisos restringidos, escritura atómica, validación (una renovación vacía nunca se guarda).
  • Ayuda: preguntas sobre el estado de servicios y lista completa de conexiones de red.

Publicación

  • 19/11/2026: repositorio público juanraul86/Eureka_CloudSpeed (licencia MIT) con pruebas automáticas (Tests/Run-Tests.ps1, 11 pruebas) y flujos de GitHub Actions.
  • Release v1.3.0 compilada en GitHub Actions: Eureka_CloudSpeed.exe y Eureka_CloudSpeed_Portable.exe, sin firmar, con huellas SHA-256 en las notas.
  • Solicitud de firma gratuita a SignPath Foundation enviada el 19/11/2026; a la espera de su revisión.

Correcciones

  • Crear-BucketsVelocidad.ps1 -Renovar: nombre del objeto de prueba duplicado (prueba-prueba-…) y un caso en el que la configuración quedó vacía.
  • Interpretación de listas JSON en Windows PowerShell 5.1 (Microsoft 365 consumo, AWS Health y Google podían mostrar un estado incorrecto).
  • RSS de Azure vacío interpretado como incidencia.
  • La compilación ya no falla si la aplicación tiene el icono en uso.

1.2.0 · 19/11/2026 · Revisión de seguridad y AWS

  • URL del test de velocidad cifradas con DPAPI; cifrado automático de las pegadas a mano.
  • Azure: SAS con políticas de acceso almacenadas (revocables), 90 días, -Renovar, -Revocar, -RotarClaves; cuentas con HTTPS, TLS 1.2, sin acceso anónimo ni replicación entre inquilinos.
  • AWS: Crear-BucketsVelocidad.ps1 (Block Public Access, sin ACL, SSE-S3, TLS ≥ 1.2, ciclo de vida) y firma SigV4 propia verificada con el ejemplo oficial de AWS; política IAM mínima.
  • Seudónimo del equipo (Ocultar el nombre del equipo, -Anonimo).
  • CSV protegidos contra inyección de fórmulas.
  • La verificación de integridad del .exe incluye los JSON del catálogo.
  • Solo se abren URL https:// procedentes del catálogo.
  • El test de velocidad no modifica las URL firmadas (antes añadía nocache).

1.1.0 · 19/11/2026 · Paridad con AzureSpeed y AWS

  • Nueva interfaz con menú lateral y una página por sección (cargada bajo demanda).
  • Secciones: Velocidad, Latencia entre regiones, Comandos (PsPing y otros), Precios de VM (Azure y EC2), Precios de modelos de IA, Regiones y zonas, Mapa de regiones, Nubes soberanas y entornos, Búsqueda de IP, Rangos de IP y Ayuda.
  • Latencia: prueba rápida de 10 rondas, panel "Tu conexión" y pestaña Mapa.
  • Datos de referencia: azure-speed-test (MIT) y Natural Earth (dominio público).
  • Motor: test de velocidad, rangos de IP y nuevos gráficos (mapa, curva de velocidad, barras).

1.0.0 · 19/11/2026 · Primera versión

  • Medición de latencia en paralelo a 75 regiones de Azure y AWS (TCP 443), con P50, P95, jitter y pérdida.
  • Interfaz WPF claro/oscuro: ranking en directo, gráficos, evolución, Azure vs AWS, modo continuo, etiquetas.
  • Exportaciones: Excel con gráficos nativos (sin Excel instalado), Power BI Desktop (histórico, .pbids, DAX, Power Query), CSV e informe HTML.
  • Modo consola para tareas programadas; lanzador .exe con verificación de integridad y versión portable.
  • Motor compilado en memoria (Smart App Control bloqueaba la DLL en caché) y scripts en UTF-8 con BOM.
